# Xianglu Xiao — Personal Research Website

A bilingual, responsive personal research website prepared for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Publish

1. Create a public GitHub repository named `XiangLuXiao.github.io`.
2. Push the `main` branch from this folder.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the source.

The included workflow publishes the site to `https://xiangluxiao.github.io/` after every push to `main`.
